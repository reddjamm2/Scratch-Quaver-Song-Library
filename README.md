# Scratch Quaver Song Library

Songs for **Scratch Quaver**, a Quaver-style 4-key rhythm game that runs on TurboWarp.
The game downloads `index.txt` at startup and fetches each song's files on demand from
`https://raw.githubusercontent.com/reddjamm2/Scratch-Quaver-Song-Library/main/`.

Charts are converted from [Quaver](https://quavergame.com) maps; all charts belong to their mappers
(listed in `index.txt`) and the music to its artists.

## Layout

```
index.txt                 every difficulty, tab separated (first line = column names)
songs/<set>/set.json      metadata for the mapset
songs/<set>/<map>.txt     chart (Q1 format, below)
songs/<set>/audio.mp3     full song
songs/<set>/preview.mp3   15 s clip for song select (starts at preview_time ms of audio.mp3)
songs/<set>/bg.jpg        background, 1280x720
songs/<set>/banner.jpg    song select banner, 422x78 (top of the background)
```

`<set>` is the Quaver mapset ID (`local-…` for unsubmitted maps), `<map>` the Quaver map ID.

## index.txt columns

`set, map, title, artist, creator, difficulty, rating, bpm, length, notes, holds, audio, preview_time, background, density, status, clan, submitted, updated, plays, combo, source`
— `rating` is Quaver's difficulty rating (empty if unknown), `length` is in ms, `density` is Quaver's
actions per second (used for health weighting). `status` is Quaver's ranked status (0 not submitted,
1 unranked, 2 ranked), `clan` 1 if clan ranked, `submitted`/`updated` are UTC dates, `plays` Quaver's
play count, `combo` max combo, `source` the song source.

## Chart format (Q1)

One line, six `;`-separated sections:

```
Q1;FLAGS;INITIAL_SV;TIMING;SVS;NOTES
```

| Section | Contents |
|---|---|
| `FLAGS` | `b` if BPM changes don't affect scroll speed |
| `INITIAL_SV` | initial scroll velocity (usually `1`) |
| `TIMING` | `time,bpm,time,bpm,…` (ms) |
| `SVS` | `time,multiplier,…` (ms) |
| `NOTES` | `<lane 0-3><ms since previous note>[~<hold length>]`, comma separated |

Example: `Q1;b;1;0,120;;0500,30,1500~250` → taps in lanes 0 and 3 at 500 ms, a 250 ms hold in lane 1 at 2000 ms.

Generated by `tools/publish_library.py` in the Scratch Quaver project.
